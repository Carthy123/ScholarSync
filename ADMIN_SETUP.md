# Administrator Setup Guide

Complete these steps before handing ScholarSync to a school.

## 1. Create the first administrator

On a new installation, open `/Account/Setup` and create the first Admin account. Protect the credentials and change the password if the account was created for demonstration purposes.

## 2. Configure the school identity

Open **Admin → School Settings** and enter:

- School name
- Academic year
- Dashboard welcome message
- School address
- School phone number
- School email address
- Primary and accent colors
- School crest or logo

The crest must be PNG, JPG, JPEG, or WEBP and no larger than 2 MB.

These settings are used on the dashboard, report cards, and fee receipts.

## 3. Create classes

Create the classes needed by the school for the active academic year. Avoid creating the same class twice for the same academic year. The normal Ghanaian progression is:

`Creche → KG 1 → KG 2 → Primary 1 → Primary 2 → Primary 3 → Primary 4 → Primary 5 → Primary 6 → Grade 7 → Grade 8 → Grade 9`

## 4. Create users and assign teachers

Open **Admin Accounts** to create Teacher accounts. Then open the class teacher assignment page and assign each teacher to the classes they manage. Teachers will only see assigned classes and their students.

## 5. Configure fees

Create a fee structure for each class, term, and academic year. The system prevents duplicate structures for the same class, term, and year.

## 6. Prepare subjects and records

Use the subjects already provided for the Ghanaian school context. Add students, record attendance, and enter grades as the school supplies the information.

## 7. Backups and audit history

Create a database backup before demonstrations and important data changes. Review **Audit History** when investigating account or record changes.

## 8. Recommended operating practice

- Use one named account per administrator or teacher.
- Do not share passwords.
- Back up the database regularly.
- Confirm the academic year before creating classes or fee structures.
- Test a report card and receipt after changing branding.
- Restrict access to the database and uploaded crest files on the hosting server.
